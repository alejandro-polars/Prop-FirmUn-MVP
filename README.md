# Prop-FirmUn-MVP

MVP designed to demonstrate production AI evidence layer integration for proprietary trading workflows.

## 🛠️ Tech Stack
* **Backend:** Python / Fast API (or your framework)
* **Frontend:** React / TypeScript (or your framework)
* **Core Logic:** Rust (High-performance processing)
* **DevOps:** Dockerized environment

## 🚀 Architecture Overview
The system is divided into three core microservices:
1. `backend`: Handles API routing and client requests.
2. `frontend`: User dashboard and visual analytics.
3. `ai_worker`: Core AI integration for evidence tracking.

*For a deeper dive into the system design, check out the `arquitectura.md` file in this repository.*
